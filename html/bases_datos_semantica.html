Concepto y Tipos de Bases de Datos

Bases de datos Relacionales

Las bases de datos relacionales organizan la información en tablas compuestas por filas y columnas, donde cada registro mantiene una estructura fija y una relación lógica entre sí. Este modelo garantiza una alta consistencia y es ideal para transacciones complejas que requieren un esquema rígido. Ejemplos líderes en la industria incluyen MySQL, PostgreSQL y Oracle.

Bases de datos No Relacionales

Las bases de datos NoSQL gestionan almacenamiento no estructurado y semiestructurado, organizando la información de forma flexible mediante documentos, clave-valor o grafos. Esto permite procesar grandes volúmenes de datos masivos y cambiantes sin depender de esquemas rígidos. Ejemplos destacados de estas tecnologías incluyen MongoDB, Cassandra, Redis y Neo4j.

Estructura de una Base de Datos Relacional

Componentes fundamentales

  • Tablas (entidades):Estructuras donde se organizan los datos.
  • Campos (atributos):Columnas que definen la tipología de información.
  • Registros (tuplas):Filas que contienen cada instancia concreta de datos.
  • Claves primarias (Primary Keys):Identificadores únicos de cada registro.

Relaciones entre tablas

Cardinalidales fundamentales

  • Relación 1:1 (Uno a uno)
  • Relación 1:N (Uno a muchos)
  • Relación N:M (Muchos a muchos)

Una Clave Foránea (Foreign Key) es un campo que vincula dos tablas al apuntar a la clave primaria de otra, estableciendo una relación directa entre sus registros. Su función principal es garantizar la integridad referencial, asegurando que los datos conectados sean válidos, consistentes y no queden duplicados ni huérfanos.
